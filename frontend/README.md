# Frontend (Next.js)

The Airbnb clone's web app. See the [main README](../README.md) for setup, architecture and deployment.

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev                  # http://localhost:3000
```

Useful scripts: `npm run build` (production build + type check), `npm run lint`.
